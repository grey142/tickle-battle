# Assets

Character A-pose stills: [characters/](characters/) (`ART_MAPPING.json`, Amateur 12 as `FirstLast.jpg`).

Bible constraints to enforce on every import:

- One shared humanoid rig and four-clip anim set (idle stand, run, tickling, laugh/squirm).
- Gear is socket overlays — never baked into clips.
- Armor leaves stomach and bare feet visible; hair must clear the neck socket.
- No gore, no sharp edges (even decorative), no ranged weapons.
- **No metal on character stills** (jewelry, hardware, cyber/synth plates, glowing metallic seams).
- Team ID is rim tint / armor accent, not bright UI blobs.
- Elara Case is player-reserved; do not assign a lobby sprite to that name.
